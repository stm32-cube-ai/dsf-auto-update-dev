# Dataset Factory – Dev Update Channel

This repository hosts *development* builds of the Dataset Factory Desktop app. It feeds the internal auto-update mechanism for QA engineers, beta partners, and ST staff who have been granted access.

> **Access notice:** Dev installers are not publicly distributed. Do not share links or binaries outside the approved testing group.

## Getting the Dev App

1. Request access to the SRA Sensor Platforms team.
2. Once approved, you’ll receive instructions for installing the dev build.
3. After the first install, the app checks this repository’s Releases feed to stay current.

Thank you for helping validate the next Dataset Factory release!
